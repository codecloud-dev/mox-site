MOXSH · 终端

moxsh

Android 液态玻璃终端。整颗应用从内核到 UI 都为「快」与「美」重新造过一遍轮子。

  • Rust 自研内核：NEON 加速、增量渲染、脏区跟踪
  • 全面兼容 Termux 包生态，*.deb 直接可装
  • proot 发行版管理：Ubuntu / Debian / Kali 一键开箱
  • 插件体系：AI 技能、悬浮玻璃终端、桌面小部件
  • 加固本地 IPC：挑战-响应 + HMAC-SHA256 鉴权

路线图 · 我们想给终端加什么

moxsh 才刚起步。下面这些，是我们打算一步步塞进「掌心的 Linux」里的东西——也欢迎来社区里加戏。

终端体验

多窗口分屏

一个屏幕开多个会话：左右分屏、标签页、滑动手势切换。手机也能当「多任务工作站」。

账户

命令云同步

登录 GitHub 后，把 shell 配置、别名、历史同步到云端。换手机不丢环境，多设备一致。

社区

脚本 / 命令市场

社区共享的一键脚本，`.mox` 包一键安装：装环境、配服务、跑运维，点一下就好。

AI

本地离线模型

断网也能问：把小模型跑在本地，解释报错、改脚本不依赖云端，隐私不出设备。

外设

桌面模式

接 OTG 键鼠、连外接显示器，手机变一台小主机：窗口、拖拽，全玻璃质感。

个性化

主题引擎

液态玻璃不止一种光。自定义光晕颜色、模糊强度、反射层，把终端调成你的那一款。
