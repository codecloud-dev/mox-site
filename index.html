为「快」与「美」造的终端

moxsh 是 MoX 的旗舰产品：内核用 Rust 重写，界面用液态玻璃重绘。每一项体验，都从底层重新考虑过。

Rust 内核

PTY、VT 解析、回滚、渲染调度、包管理验签全部用 Rust，内存安全且快。

液态玻璃界面

实时模糊、半透明层级、顶部高光反射与折射边——像真玻璃，不像贴图。

Termux 兼容

直接吃 Termux 官方源，*.deb 能装能跑，命令用法与生态完全一致。

PRoot 发行版

Ubuntu / Debian / Kali / Alpine 一键安装，隔离环境随便玩，不碰系统。

AI 助手

解释报错、写脚本、管环境；支持 DeepSeek / 智谱 / 通义 / Kimi 等模型。

加固 IPC

挑战-响应 + HMAC-SHA256 鉴权，跨进程调用不裸奔，插件也安全。

一个 MoX 账号，串起所有设备

所有 MoX 产品共用同一套身份（由 mox-id 后端提供）。登录后，普通用户和管理员各取所需。

普通用户 · 云同步

多设备配置、命令历史实时同步；AI 助手额度跨设备共享。任意 GitHub 用户都能登录，免费起步。

管理员 · 管理后台

登录后自动出现「管理后台」入口，用于会员档位、计费对账、内容管理与运营数据。入口是秘径，只下发给管理员本人。

安全说明

通过 GitHub 登录，凭证仅存本地；云同步内容在客户端加密后才上传，服务端看不到明文。支持一键退出。

路线图 · MoX 生态演进

我们按阶段把「桌面级工具搬进掌心」这件事做扎实。已交付的已经能用，进行中的正在打磨，规划中的是接下来的方向。

阶段一✅ 已交付

moxsh 1.0 · 液态玻璃终端

Android 上的液态玻璃终端：Rust 自研内核，全面兼容 Termux 生态，无需 root、装上即用。

  • Rust PTY / VT 解析 / 回滚 / 渲染调度
  • Termux 兼容 + PRoot 发行版（Ubuntu / Debian / Kali / Alpine）
  • 加固 IPC：挑战-响应 + HMAC-SHA256 鉴权
阶段二✅ 已交付

mox-id · 统一身份与云同步

MoX 的账号底座：任意 GitHub 用户一键登录，云同步、会员、计费、管理后台都从这里走。

  • GitHub OAuth 登录，凭证仅存本地
  • 多设备配置 / 命令历史实时云同步（客户端加密）
  • 会员档位、计费对账、隐藏秘径管理后台
阶段三✅ 已交付

moxwebgpu 1.0 · WebGPU 计算框架

零依赖的 WebGPU 通用计算框架：类型化张量、原始 WGSL Kernel、惰性计算图，算力下推到访客的浏览器 GPU。

  • 30+ 算子 + 任意轴归约，27 个真实 GPU e2e
  • 自动微分（反向模式，叠加在惰性图上）
  • npm 发布 + 在线演示 + 文档站
阶段四🔄 进行中

moxsh 性能与 AI 深化

在旗舰终端上把体验与智能再推一步：更高帧率、更低功耗，以及真正跑得动的端侧 AI。

  • 120Hz 渲染 + 字体图集（atlas）复用
  • NEON 向量化热点路径
  • AI 端侧推理（AiProvider.Local 预留）

我们的愿景

不是又一个「 App 工厂」的产物。MoX 想做的事很朴素，但很较真。

桌面级能力，装进掌心

手机不是「凑合用的小屏」，而是能跑真终端、真 GPU 计算的随身工作站。我们按这个标准重做每一处体验。

算力下推到你的设备

隐私优先：云同步内容在客户端加密后才上传，服务端看不到明文；能本地算的，绝不搬去云端。

小而美，快速迭代。一个人对品质负全责，AI 负责把重复劳动吃下，让创意更快落地。
