A terminal built for speed & beauty

The core is rewritten in Rust; the UI is redrawn in liquid glass. Every experience is reconsidered from the ground up.

Rust core

PTY, VT parsing, scrollback, render scheduling, package signing — all in Rust. Memory-safe and fast.

Liquid-glass UI

Real-time blur, translucent layers, top highlight and refractive edge — like real glass, not a sticker.

Termux compatible

Eats the official Termux repos directly — *.deb installs and runs, commands behave the same.

PRoot distros

Ubuntu / Debian / Kali / Alpine one-tap. Isolated environment, no touching the system.

AI assistant

Explain errors, write scripts, manage environments. Supports DeepSeek / Zhipu / Qwen / Kimi and more.

Hardened IPC

Challenge-response + HMAC-SHA256 auth. Cross-process calls never run naked; plugins stay safe.
