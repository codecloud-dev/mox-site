A terminal built for speed & beauty

moxsh is MoX's flagship: Rust core rewritten from scratch, UI redrawn in liquid glass. Every detail rethought from the bottom up.

Rust core

PTY, VT parsing, scrollback, render scheduling, package signing — all in Rust. Memory-safe and fast.

Liquid-glass UI

Live blur, translucent layers, top highlight & refraction edges — like real glass, not a sticker.

Termux-compatible

Eats the official Termux repos; *.deb installs and runs; commands & ecosystem are identical.

PRoot distros

Ubuntu / Debian / Kali / Alpine one-tap; isolated sandbox to play in, without touching the system.

AI assistant

Explains errors, writes scripts, manages env; supports DeepSeek / Zhipu / Qwen / Kimi and more.

Hardened IPC

Challenge-response + HMAC-SHA256 auth. Cross-process calls never run naked; plugins stay safe.

One MoX account, every device

All MoX products share one identity (powered by the mox-id backend). After sign-in, normal users and admins each get what they need.

Normal users · cloud sync

Multi-device config and command history sync in real time; AI quota shared across devices. Any GitHub user can sign in, free to start.

Admins · admin console

An "Admin console" entry appears after sign-in — for membership tiers, billing reconciliation, content & ops. The entry is a secret path, delivered only to admins.

Security

Sign in with GitHub; credentials stay local. Cloud-sync data is client-encrypted before upload — the server never sees plaintext. One-tap sign-out.

Want to try first?

Tap "Sign in" at the top-right to enter with your GitHub account. Normal users get cloud sync right away; admins see a dedicated console entry.
