1 三行嵌入任意网站

在页面里贴一段 <script>，你的访客的 GPU 当场就能算：
<script src="https://mox-site.pages.dev/webgpu/moxwebgpu.browser.js"></script>
<script>
  MoxWebGPU.mox.init().then(gpu => {
    gpu.tensor([1, 2, 3]).add(1).sum().then(r => console.log('结果 =', r));
  });
</script>

2 多种引入方式

CDN · 全局
IIFE 包，挂到 window.MoxWebGPU，最省事：
<script src="https://mox-site.pages.dev/webgpu/moxwebgpu.browser.js"></script>
<script>
  const gpu = await MoxWebGPU.mox.init();
</script>
npm
发布后即可（当前待发布，先走 CDN）：
npm i @mox/moxwebgpu

import { mox } from '@mox/moxwebgpu';
const gpu = await mox.init();
ESM CDN
发布后可直接 import（esm.sh / unpkg）：
import { mox } from 'https://esm.sh/@mox/moxwebgpu';
const gpu = await mox.init();
边缘打包
无原生依赖，直接上 Cloudflare Workers：
esbuild worker.ts --bundle \
  --format=esm --outfile=dist/worker.js
